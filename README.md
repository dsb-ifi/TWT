# A Smaller Transformer in Your Transformer

Code release for **Transformer-Within-Transformer (TWT)**, accompanying the BMVC 2026 paper *A Smaller Transformer in Your Transformer*.

TWT identifies contiguous computational phases in a Vision Transformer, selects a representative transformer layer for each phase, and distils the resulting depth-reduced student with boundary-level and final-feature supervision.
